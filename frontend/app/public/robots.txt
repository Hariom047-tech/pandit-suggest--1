# Search engines index whatever they can reach. An admin panel that appears in
# Google is found by people who were never looking for it — this is the most
# common way private surfaces get discovered, far more common than path guessing.
#
# This is NOT an access control. Disallow is a request, honoured by mainstream
# crawlers and ignored by everything hostile. Real access control is the
# password + TOTP gate on the API, plus (recommended) an IP allow-list in nginx.
#
# Disallow is also NOT a way to remove a page from search results. It blocks
# crawling, not indexing: Google can index a URL it has only ever seen in a
# link, and while it is forbidden from fetching the page it can never see the
# `noindex` on it — so the URL sits in the index permanently, with a title
# Google invents because it has never read the page. That is how a result
# titled "PanditSuggest Logo" (the header image's alt text) appeared for this
# site. The private routes below are therefore deliberately NOT listed here
# any more: nginx serves them `X-Robots-Tag: noindex, follow` instead
# (docker/nginx/default.conf), which is only any use if the crawler is
# allowed to fetch them and read it.
#
# What stays listed is what must never be FETCHED, where indexing is not the
# concern: the API, uploaded media, and the admin panel.

User-agent: *
Disallow: /admin-panel
Disallow: /admin-panel/
Disallow: /uploads/
Disallow: /api/

Allow: /

Sitemap: https://www.panditsuggest.com/sitemap.xml
